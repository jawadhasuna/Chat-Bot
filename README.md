# Atom Chatbot

**Live app:** https://atomchatbot.vercel.app

Atom Chatbot is a conversational AI assistant in the Atom suite — a text and voice chatbot you can type to or talk to. It's a lightweight HTML/JS frontend backed by a Vercel serverless function calling Llama 3.3 70B via Hugging Face, with Web Speech API support layered in so you can speak your messages and hear the replies read back to you.
